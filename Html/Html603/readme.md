# Feladat 0603 - Táblázat javítása

A feladat során egy elírt HTML táblázatot kell kijavítani.

## Javítások:
1. **TR tag javítása**: A hibás `t` tageket `tr`-re (table row) javítottam.
2. **TD tag javítása**: A cellák záró tageit `</t>`-ről `</td>`-re javítottam.
3. **Struktúra**: Ellenőriztem a sorok és cellák helyes lezárását.
