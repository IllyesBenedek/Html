# Feladat 002 - Két fűzfa

## Elvégzendő lépések:
1. **Tartalom**: Az `adat.txt` beillesztése a törzsbe.
2. **Nyelv**: Magyar (`hu`) beállítása.
3. **Cím**: Böngészőfül címe: `Két fűzfa`.
4. **Főcím**: `<h1>Két fűzfa</h1>`.
5. **Tagolás**: 3 bekezdés (`p`) kialakítása.
6. **Alcímek**: `h2` címek: `A jövedelem`, `A kollégium`, `Az orákulum`.
7. **Kiemelés**: 3. bekezdésben "bevette magát" félkövér.
8. **Dőlt**: 2. bekezdésben "időszerint" dőlt.
9. **Komment**: Név és aktuális dátum a forráskódban.
