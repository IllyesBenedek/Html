# Feladat 211 - Navigációs sáv készítése

A Felbecs Kft. weboldalát kell kiegészítenie egy navigációs sávval mindhárom oldalon.

## Feladatok:
1. **Navigáció helye**: Készítsen navigációs sávot a `<h1>` főcím alá.
2. **HTML elem**: A navigációs sávot az erre a célra létrehozott `<nav>` HTML elemmel alakítsa ki.
3. **Lista használata**: A `<nav>` elemen belül egy listával (`<ul>`) alakítsa tovább a navigációs sávot.
4. **Hiperhivatkozások**: A lista elemei (`<li>`) három hiperhivatkozást (`<a>`) tartalmazzanak.
5. **Célpontok**: A hivatkozások a csomagban található 3 weblapra mutassanak:
   * `index.html`
   * `termekek.html`
   * `partnerek.html`
6. **Szövegek**: A hiperhivatkozások szövegei igazodjanak a tartalomhoz (pl. Főoldal, Termékek, Partnerek).
