# Feladat 0601 - Hibás HTML elemek javítása

A feladat során egy hibás HTML struktúrát kell helyreállítani.

## Javítások:
1. **HTML/HEAD/META**: A hibás `htm` és `hea` tageket `html` és `head` tagre, a `carset` attribútumot `charset`-re javítottam.
2. **BODY/DIV**: A `di` elírt tageket `div`-re javítottam.
3. **DOBOZOK SZÁMA**: Ellenőriztem, hogy pontosan 5 darab `doboz` osztályú elem legyen.
4. **ID-K ELLENŐRZÉSE**: A `d1`-től `d5`-ig terjedő id-k meglétét ellenőriztem.
