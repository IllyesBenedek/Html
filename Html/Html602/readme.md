# Feladat 0602 - Hajó struktúra javítása

A feladat során egy elírt HTML-t kell kijavítani.

## Javítások:
1. **Szintaxis**: Javítottam az elírt tageket (`/li` -> `</li>`, `olo` -> `ol`, `l` -> `li`).
2. **Attribútumok**: Kijavítottam az elírt `clas` attribútumot `class`-ra.
3. **Struktúra**: Megfelelően lezártam a listaelemeket és javítottam a beágyazott listát.
