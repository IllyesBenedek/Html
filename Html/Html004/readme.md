# Feladat 004 - HP-UX

## Elvégzendő lépések:
1. **Tartalom**: A `hpux.txt` állomány tartalmának beillesztése a törzsbe.
2. **Nyelv**: Magyar (`hu`) beállítása.
3. **Cím**: Böngészőfül címe: `HP-UX`.
4. **Főcím**: `<h1>HP-UX</h1>`.
5. **Tagolás**: A platformok listája egyetlen bekezdés legyen, vesszővel elválasztva.
6. **Rövidítés**: A „HP 9000” szövegrészt jelölje meg rövidítésnek (`abbr`).
7. **Kiemelés**: A „HP Integral PC” szövegrészt jelölje meg kiemeltnek (`strong`).
8. **Alcím**: A támogatás bekezdés előtt legyen `<h2>Támogatás</h2>`.
9. **Komment**: Név és aktuális dátum a forráskódban.
